# Threat Intelligence

Repository dedicated to threat intelligence research, ATT&CK mapping, adversary tracking, detection engineering and malware-related analysis.

This repository focuses on operational threat intelligence, emphasizing technical analysis, TTP correlation and defensive applicability.
